# 游戏内着色器编译与缓存系统

## 项目描述

游戏内着色器编译与缓存系统的bug修复项目。核心模块 `rendering/shader_compiler.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 着色器编译完全没做只能用预编译的着色器
- 着色器缓存完全没做不能缓存编译结果
- 着色器变体完全没做不能管理着色器变体
- 着色器热重载完全没做不能运行时修改着色器
- 着色器调试完全没做不能调试着色器

## 运行测试

```bash
python -m pytest tests/test_shader_compiler.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
